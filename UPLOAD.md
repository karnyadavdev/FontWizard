# How to upload (one commit)

1. Open https://github.com/karnyadavdev/FontWizard at the repo ROOT.
2. Click **Add file** -> **Upload files** (or drag the items below onto the page).
3. Drag these TWO things from this folder into the upload area together:
   - the **App** folder  (merges into the existing App -> overwrites src, adds journal.py, updates requirements.txt)
   - the **README.md** file  (overwrites the root README)
4. Commit message: `Update Font Wizard to latest version`
5. Click **Commit changes**.

Do NOT drag the `github-upload` folder itself, and do NOT drag `UPLOAD.md` / `third-party-notices.txt` / `build.bat`.
